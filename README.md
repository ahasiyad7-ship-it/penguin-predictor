# 🐧 Penguin Species Predictor

Predict the species of a penguin (Adelie, Gentoo, Chinstrap) based on its physical measurements using Machine Learning.

**Live Demo:** https://penguin-predictor.streamlit.app

## ✨ Features
- Interactive sliders to input bill length, bill depth, flipper length and body mass
- Real-time prediction using Random Forest Classifier
- Beautiful penguin images for each species
- Built with Streamlit

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas & Numpy

## 🚀 How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
